04b — FAQ Accordion
Bieži uzdotie jautājumi — brenža akordeona bloks

Izmanto <details>/<summary> — bez JS. Ikonka + rotējas 45° (→ ×) kad atvērts. Klases: .faq-dl-list / .faq-dl-item / .faq-dl-toggle / .faq-dl-body

📌 Заголовок всегда по центру — добавляй класс .faq-dl-heading к <h2> над блоком. CSS: text-align:center; margin-bottom:2rem;

Kā darbojas akordeona bloks?+
Izmanto natīvo HTML <details> elementu — bez JavaScript. Atvērot, ikonka + rotējas 45° un kļūst par ×. Fons un animācija tiek kontrolēta tikai ar CSS.
Kādas klases jāizmanto?+
Apvalkojiet sarakstu ar .faq-dl-list, katru jautājumu ar .faq-dl-item, ikonkai pievienojiet .faq-dl-toggle, un atbildei — .faq-dl-body.
<div class="faq-dl-list">
  <details class="faq-dl-item">
    <summary>Jautājuma teksts<span class="faq-dl-toggle">+</span></summary>
    <div class="faq-dl-body">Atbildes teksts</div>
  </details>
</div>

/* CSS — styles.css */
.faq-dl-item { border-bottom: 1px solid var(--line); }
.faq-dl-item:first-child { border-top: 1px solid var(--line); }
.faq-dl-item summary { font-weight:600; display:flex; justify-content:space-between; padding:.9rem 0; }
.faq-dl-toggle { font-size:1.3rem; transition:transform .25s; }
.faq-dl-item[open] .faq-dl-toggle { transform:rotate(45deg); }
.faq-dl-body { padding:.1rem 0 1.1rem; color:var(--text-2); font-size:.93rem; }
